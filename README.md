# BetterLitematica

Minecraft Fabric 投影模组，支持投影显示、编辑、校验和打印。

从 [Releases](https://github.com/IMAX9D/BetterLitematica/releases) 下载与 Minecraft 版本对应的 JAR，与 Fabric API 一起放入 `mods`。默认按 Z + X 打开主界面。

支持版本见 [targets.json](targets.json)。使用 JDK 25，运行 `./scripts/build.ps1 -AllVersions` 构建全部版本。

共存时接管 Litematica 的投影渲染、输入和简易放置，litematica-printer 的打印及快捷键，以及 Tweakeroo 中与施工冲突的放置、自动点击和换物品功能。
