# 简单放置 · 0.3.13

在设置中开启“简单放置”，或使用 M+E 切换。对准可触及的投影方块，使用游戏的“使用”按键（默认右键）；“按住连续”开启时每 4 tick 尝试一次。主手木棍启用工具时仍用于选区/移动摆放。

生存模式从快捷栏和背包选取对应材料，通过正常库存交换和放置交互完成；创造模式补入对应物品。目标不存在时保留原版操作；目标存在时拦截原版额外右键流程，避免重复使用物品。暂停连续放置于菜单、窗口失焦、旁观、使用物品及关闭总渲染时。

普通完整方块可对悬空投影直接使用。上下半砖和双半砖通过普通放置状态预测校验；双半砖允许先放第一块。目标有实物遮挡、区块未加载、距离不足或已匹配时跳过。不改写世界、不伪造玩家朝向，不实现服务器准确放置扩展协议。楼梯、门等朝向依赖原版玩家朝向；无法匹配时跳过。液体、盆栽、多层积雪等多步状态工作流尚不支持。不代表全部 Litematica Easy Place 行为等价。

设置沿用 easyPlace 配置键，兼容已有配置；新快捷键在旧配置缺失时使用 M+E。错误提示限频，不每 tick 刷屏。

验证：58 项核心检查、43 项真实 Minecraft 无窗口检查通过；新增基础方块、错误材料、空预测、半砖/双半砖、朝向拒绝和命中位置边界共 12 项检查。完整构建通过。没有启动游戏；库存网络同步、按键事件、实际放置、服务器接受行为和连续放置须游戏内验收。
