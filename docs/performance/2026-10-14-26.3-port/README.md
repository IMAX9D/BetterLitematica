# 26.3 渲染适配验证

26.3 的 0.4.4 包接入了后台投影网格生成、共享顶点页、绘制指令缓存、按可见缺口分配加载预算，以及六面连通性地形遍历。原版仍负责地形构建调度、共享地形缓冲、透明排序和 OpenGL / Vulkan 后端；没有把 1.20.1 的 OpenGL 钩子直接套用到新引擎。

模型和染色回调在游戏线程提取。只对已知原版模型构建不可变快照，未知模型保留游戏线程路径；方块实体也保留原有线程。加权模型和组合模型保留原版随机选择顺序。

验证使用 Java 25、Fabric Loader 0.19.3、Fabric API 0.160.5+26.3，没有提高原先声明的依赖下限。

| 检查 | 结果 |
|---|---|
| 构建、访问权限声明 | 通过 |
| 放置输入 | 1,014 项检查通过 |
| 设置 | 97 项说明、35 个显式控件绑定、37 个原因 ID 通过 |
| 加载兼容性 | 448 个类、16 个 Mixin 目标加载通过 |
| 模型快照 | 419 种状态，14,665 次与原版模型的几何比较一致 |
| OpenGL 游戏验证 | 后台生成、半透明投影、移动、不透明投影、卸载通过，截图已检查 |
| Vulkan 游戏验证 | 同上 |

真实游戏验证使用独立副本、12 个方块的小投影和 4 区块视距，并设置 `ActiveProcessorCount=4`。首次截图被旧验证世界的实体方块遮挡，清除副本中的遮挡后重新完成了两种后端的截图验证。测试驱动没有打入交付 JAR。

这不是性能对照测试，也不证明大型投影、所有地形和第三方渲染模组都已兼容。尚未测 26.3 星空树路线、帧时间尖峰或长时间运行；1.20.1 的性能结果不能套用到 26.3。Iris、Canvas 等仍只有避让策略，没有本轮实测。
