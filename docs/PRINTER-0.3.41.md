# 0.3.41 多投影施工与附近线框

Caps Lock 和打印机页面现在控制同一个全局任务。所有启用摆放共同参与，不再沿用上次启动时绑定的单个投影；选中另一个投影不会改变施工集合。显示开关仅控制画面，停用摆放才排除施工。新增、移除、停用、重新启用或变换投影后，旧任务代际失效并自动重新采样。

多个投影共用扫描、材料批次、换料状态、放置节奏和时间预算。重叠位置沿用投影合成顺序及 ALL/NON_AIR/NONE 规则，执行前重新核对最终期望状态，避免不同投影来回覆盖。未知源数据或世界区块不视为空气。采样区段缓存最多 64 个，每区段最多 256 个候选子区域，超预算保持 UNKNOWN。

玩家可达范围内（最大 5 格），未放置目标显示橙色线框，错误方块或属性显示红色线框。线框透明度以 1.8 秒周期变化，现有蓝色施工反馈优先，不叠色。没有启动打印机也会显示；沿用“施工高亮”总开关与穿透设置。当前分层范围外、未知状态和已匹配位置不显示。世界更新立即清除已匹配的现有标记。

附近检查与全图材料分析无关，每 tick 最多访问 256 格、协作式 0.75 ms 检查额度、最多缓存 2048 个标记；每帧只绘制缓存且做视锥剔除。总渲染关闭时停止该检查。此额度不是对 JVM 调度、采样器创建或 GC 的硬实时保证。
