# BetterLitematica 0.4.17 全功能推广

全部 31 个目标已构建，保留上版全部功能类；公共 core、IO、runtime 在剔除调试信息、重建常量池后，规范化字节码在所有产物中完全一致。backpack 保持独立兼容包，仅对应 Minecraft 1.20.1。

## 验证结果

- 核心回归：139 项，2,513,993 条断言。
- 每个游戏目标：设置、连续放置、用户流程、投影管线、地形挂接、全功能推广检查均通过。
- 读取预算：实际 1/2/10 GiB JVM、60%/75% 配置、非法值回退、默认配置生成、恶意数组长度与取消检查。
- 教堂：501,396,805 格，31,681,915 个非空气方块，1,103 种状态，16,325 个缓存段，3,999 个方块实体、35 个实体；源文件 SHA-256 未改变。
- 分层：五个正式资源变体展开实际 include 后运行显卡测试；原逻辑每变体复现 24 个边界错误，修复后共 665 条检查通过。
- backpack：78,493 条库存策略检查、2,799 条批次检查、17 个桥接字段、9 个实际垃圾桶协议检查、8 个 Mixin 目标/13 个处理器，以及 Fabric 与 backpack 联合回包链检查。

本次未启动 Minecraft，未做新版逐版本游戏内截图与服务器打印吞吐验收。构建和离线回归通过不等于这两项已实测。游戏实例内文件未替换。
