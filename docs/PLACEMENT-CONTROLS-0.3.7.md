# 0.3.7 投影快捷操作与独立不透明度

M 菜单每条投影右侧提供配置、显示：是/否、删除。配置选中该投影并打开设置；显示开关与删除按 UUID 操作，不切换其他选中项。删除仅移除摆放及缓存资源，源文件保留；删除选中项后选中第一个剩余投影。导入中的项目也可取消删除。长名称悬停显示完整内容。

配置中的不透明度范围为 0.05–1，1 为完全不透明。调整仅影响这一投影，不重建网格。旧的分层页面保留批量设置，会覆盖当前全部投影，并作为后续新加载投影的默认值。复制和项目版本保留单项值。设置格式升级到 v2，读取 v1 时逐项继承原有全局值；不支持旧程序读取新设置格式。

所有投影仍共用一个深度缓冲及离屏颜色目标。最近表面写入自己的不透明度，最后合成一次；贴图透明镂空检测在应用投影不透明度之前完成，避免低于 10% 时整块被丢弃。完全相同源文件与变换的重叠实例采用最高不透明度；不同投影交叠仍采用最近表面，不实现多层透视混合。

验证：58 项核心测试 / 335,976 次断言、31 项 Minecraft 无窗口检查通过，完整构建成功。新增持久化、独立值、非法数值、复制保留、v1 迁移及再次保存检查。没有启动游戏；GPU 着色器运行效果、界面交互及实际重叠场景尚待游戏验收。
