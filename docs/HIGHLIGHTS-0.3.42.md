# 附近线框可见性修正

0.3.41 的实际 framebuffer 对照确认：停止打印时，橙色缺块与红色错块线框都能绘制；关闭高亮后消失。开启高速打印时，可达范围内的缺块在同 tick 被补齐，标记立即删除或让位给蓝色施工反馈。观察范围与施工范围重合，导致玩家没有看到提前提示。对照截图及像素统计见 [0.3.41 实际画面](../validation/nearby-render-0.3.41/README.md)。

0.3.42 将观察半径独立为 8 格，不改变打印可达距离。每 tick 最多推进 512 个游标项，仍使用 0.75 ms 协作式检查额度和 2048 条缓存上限；即使准备采样器耗尽额度，也至少推进一个游标项，避免完全停滞。已完成格立即消隐、蓝色动作反馈优先、未知数据不高亮等行为保留。初次范围扫描为增量完成。

117 项核心测试 / 562935 次断言、96754 项适配检查和完整构建通过。新增超出施工距离的缺块/错块预览及准备超时最小进展检查。日志：[build-0.3.42.txt](../validation/build-0.3.42.txt)。

实际游戏渲染验收见 [截图和报告](../validation/nearby-render-0.3.42/README.md)：打印保持运行、近排完成 6 次操作并显示蓝/青施工反馈；距离 6.53–6.99 格的远排保持 5 个 MISSING 与 1 个 WRONG，实际画面仍能看到橙红线框，远排像素区域测得 1701 橙 / 218 红，关闭高亮对照为 0 / 0。采用独立隐藏窗口与测试存档，测试进程已退出，没有操作用户正在运行的游戏。没有测量持续 FPS 或多人服表现。
