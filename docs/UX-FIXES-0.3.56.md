# 用户体验缺陷修复 · 0.3.56-dev

2026-09-24。依据用户提供的《BetterLitematica 用户体验评审：源码核查与复现记录》，本批处理五项确定缺陷，不代表评审所有产品建议已实现。

## 修改

- 目录搜索先匹配再限制返回数量，移除扫描前 10,000 项和总时长截断。后台分片扫描、200 ms 搜索防抖、旧请求取消；每次最多显示 1,000 个匹配项，更多时可缩小关键词。目录扫描与会话保存使用独立工作线程，路径边界和软链接限制保留。
- 主菜单键统一由模组设置管理，移除 Minecraft 控制页中不起实际作用的重复绑定。
- 快捷轮盘默认 Tab，可在设置中改为其他单个非修饰键或清空禁用；改键后不再占用原按键。轮盘与组合快捷键冲突会拒绝，原生游戏按键重叠会提示。轮盘暂不接受组合键或鼠标键。
- 子区域坐标按区域保留当前页面的未提交草稿，切换区域、旋转、镜像或刷新控件不丢输入；应用失败保留草稿，成功应用、移到玩家或重置后只清理该区域草稿。关闭页面后的草稿持久化不在本批范围。
- 校验搜索匹配应放与实际方块的本地化名称，同时保留 ID、状态和错误类型匹配；名称缓存有界，语言变更时失效。

隐藏投影仍可打印；施工模式保持独立叠加；材料总量仍来自完整投影文件。
