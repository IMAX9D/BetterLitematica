# 0.3.44 投影表面与入口整理

主菜单的功能区首行放置全局打印机入口，不需要先选中投影。单投影配置页保留材料清单、投影校验、投影编辑、子区域四个并列入口；材料页绑定所打开的投影。材料与校验采用独立标题及固定模式，移除互相切换标签，搜索框使用释放出的宽度。

错误位置的投影表面使用红色调，保持原纹理与摆放不透明度。缺失位置保持正常蓝色调；已正确放置的格子沿用即时隐藏机制。红色线框及独立“错误高亮置顶”设置保留。

使用每区段错误掩码与已有方块 quad 归属，复用顶点缓冲分蓝/红绘制。正常区段不新增逐 part 的色调上传；只有错误区段切换颜色。新增掩码与分段对象开销计入缓存预算。世界方块更新立即修改已有几何的颜色/隐藏状态；原先正确而已被省略的几何仍需既有局部重建恢复。独立实体无方块归属，保持原色。
