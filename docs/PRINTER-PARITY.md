## 0.3.39 候选接入范围

在每份投影的配置页增加“打印机”；M+B 打开当前投影打印页，CapsLock 开始/暂停，Ctrl+CapsLock 停止。页面绑定投影 UUID；设置当前全局共用。开始需要玩家明确操作，打开菜单、聊天、背包、失焦或手动施工会暂停。工作状态不会保存到下一次连接。

## 服务端沿用要求

普通施工使用原版交互，不强制安装新的 BetterLitematica 服务端组件。准确协议和补给仅使用已有 Carpet Extra / 兼容 V3 / QuickShulker / AxShulkers / TakeItOut 的支持。破基岩沿用已安装客户端 BedrockMiner 或 BlockMiner；服务器是否允许仍由其规则决定。仅看到通道存在不能证明准确放置规则已启用。现代 Servux、ChainVein、QuickDirect、世界容器 TakeItOut 等适配仍属缺口，不能把新版 API 当作 1.20.1 兼容承诺。
