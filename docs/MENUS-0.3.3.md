# 0.3.3 独立菜单安全区

菜单使用固定 800×620 设计画布。基于窗口 framebuffer 真实像素，四边各留 5% 安全边距；缩放系数为 min(窗口宽×0.90/800, 窗口高×0.90/620)，画布居中。不同宽高比保持比例并留白，不横向拉伸。

游戏原生 GUI 缩放只用于抵消 Minecraft 的投影矩阵比例，不决定菜单排版、字号、按钮大小和列表容量。全部 MenuScreen 页面布局使用固定画布尺寸；窗口大小变化时重新计算外层缩放。默认字体继续使用游戏字体资源，文本编辑复用原版输入行为，但输入框外观和所有菜单尺寸由独立画布控制。

鼠标点击、松开、移动、拖动和滚轮位置转换到画布坐标；拖动距离独立转换。悬停取窗口原始鼠标坐标，避免高 GUI 倍率造成整数坐标量化。裁剪转换到真实 framebuffer 像素，并处理 OpenGL 底部原点；文本框在 1.20.1 无内部 scissor，菜单统一管理裁剪。悬停长文本在同一画布内绘制。

已核对本机 1.20.1 映射类字节码：GameRenderer 正交投影使用 framebuffer/scaleFactor；Mouse 事件使用 scaledWidth/scaledHeight；DrawContext.enableScissor 不应用矩阵栈。没有修改用户的全局 GUI 缩放选项。

新增回归检查：7 种物理窗口尺寸（含奇数尺寸、竖屏、超宽屏和 4K）×6 种宿主 GUI 倍率（1/2/3/4/6/1.5），验证物理坐标不变、5% 安全边距、鼠标往返、拖动距离、裁剪一致性及越界截断。共 57 项核心测试、335,968 次断言通过；22 项 Minecraft 无窗口适配检查通过；完整构建通过。

本轮未启动游戏，尚无实际画面与输入操作验收。上面的坐标检查是自动化数学回归，不是截图验收。libs 仅保留最新 0.3.3-dev.jar。
