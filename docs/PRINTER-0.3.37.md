# 0.3.37：移动响应与完成消隐

## 移动打印

旧路径每次跨方块更新中心，都会重新开始扫描，清空候选并丢弃发现结果。连续移动时重复扫描前段，后段经常没有机会提交。

现在保留仍可达的队列、异步结果、位置冷却和等待事务。完整扫描持续推进，移动补查新范围与旧范围的差集；最多一份活动前沿和一份合并等待前沿，完整扫描至少获得四分之一扫描步骤。完全离开当前范围的扫描才被替换。遍历仍遵守范围形状和实时可达性；设置、源或会话改变仍按原规则失效。

空队列的同步补页不再等待后台发现 future 腾位置。关闭空气放置时，只剔除六邻均已加载且为空气、实际无法点击支撑面的普通候选；流体、调节、破坏和未知邻区继续正常处理。实际执行前仍核对世界加载、范围、源目标及观察状态，没有取消安全检查或改变服务端协议。共享工作预算、手持材料优先与公平性保留。

## 完成格消隐

旧路径只标记区段重建，已放置格仍显示旧网格直到排到构建和上传。

现在世界方块变化直接在客户端线程更新区段的 4096 位遮罩。每组四边形保存源格归属，普通模型、流体、方块实体模型和朝向玩家的光源标记使用同一条路径。下一次绘制跳过已完成格；既不输出颜色，也不写深度。判断仍要求区块已加载且变换后的完整状态匹配，不按发送动作数量提前隐藏。

遮罩只在变化时重算可见索引段，局部隐藏通过一次 glMultiDrawElements 绘制；部件全显仍沿用普通 draw，全隐不提交。读取当前共享索引类型，兼容共享缓冲扩容后的 ushort/uint 切换。归属、范围缓存、稀疏状态和位集计入原有网格额度，使用固定 48 KiB 渲染线程索引临时缓冲。

旧网格和在建替换共享遮罩。已保留几何可以直接恢复；首次构建时已经完成而省略的格被破坏后仍需局部重建，旧完整区段保留至替换。区块加载/卸载继续走有界刷新；极端重叠区域点查询超出 64 个结果或 2048 个节点时降级刷新。故不承诺这些恢复/降级路径都在一帧完成。

材料完整统计、源数据、投影变换和打印目标不受绘制遮罩影响。
