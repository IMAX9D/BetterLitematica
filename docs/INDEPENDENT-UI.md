# 独立 UI 叠加层 · 0.3.28

这是本项目后续菜单的统一绘制基础。MenuScreen 保留导航和布局组织；IndependentUi 在游戏窗口内使用真实 framebuffer 像素绘制面板和文字。它没有另开桌面窗口，也没有把整个低分辨率菜单截图放大。

## 字体与显示

- 使用系统字体，优先微软雅黑（Microsoft YaHei），其次雅黑 UI、黑体（SimHei）、苹方（PingFang）、Heiti、Noto/思源及文泉驿等已安装的中文字体。只选择实际存在且覆盖菜单常用字符的字体；最后使用 Java 逻辑字体回退。JAR 不打包字体文件，也不下载或安装字体。
- 字体发现仍在后台线程进行，测量、光标和抗锯齿均沿用同一字体。系统完全没有中文字体时，日志会提示缺失；需要用户安装中文字体。
- OutlineFont 通过 Java2D TextLayout 在最终整数像素字号下生成灰度抗锯齿文字图片。菜单的布局比例继续由 UiViewport 计算，字号改变使用新缓存键重新生成。
- GPU 上以 1:1 像素尺寸绘制生成结果，坐标对齐到整数像素。原生 GUI scale 仅被抵消，不作为文字纹理的放大倍率。
- 标题、说明、按钮、列表、状态、长文字提示、输入文本均使用这一字体路径。普通菜单绘制不调用 Minecraft TextRenderer。
- 输入框复用 TextFieldWidget 的编辑、快捷键、剪贴板模型，但向其传入空原生字体引用；绘制、测量、鼠标光标定位、选区和横向滚动使用独立字体。没有声称新增 Minecraft 原本不具备的输入法支持。
- 新文字首次出现会后台生成，随后逐批上传，因此首次打开或更换字号可能有短暂文字填充过程。

## 缓存和线程

字体加载与文字栅格化位于单独后台 worker；最多 24 个待完成文字请求，执行器队列限 32。单份文字图片限 524288 像素，最多 2048 个 UTF-16 单元。

纹理缓存在渲染线程创建与释放，上限 16 MiB / 256 条。纹理的 NativeImage CPU 副本、待完成结果和字体数据另占内存，16 MiB 不是整个 UI 的总内存上限。每帧最多上传 6 项，累计达到 1 MiB 后停止继续上传（最后一项可能超过该阈值）。宽度与截断结果各保留最多 1024 项。

资源重载清理纹理与待处理结果；客户端关闭停止 worker 并释放纹理。裁剪以物理像素计算，嵌套输入框裁剪与父级内容区求交，退出后恢复原来的裁剪栈。

## 后续扩展约定

新增菜单继承 MenuScreen，并使用其按钮/字段工厂。文字测量、截断、绘制必须走 IndependentUi / OutlineFont；不得再混用原生像素字体或对文字图片施加面板缩放。新浮层应沿用同一物理坐标和嵌套裁剪机制。

本次范围是模组菜单；游戏本身的聊天/原生 HUD 等仍由 Minecraft 管理。

## 历史验证（0.3.5 内置字体版本）

57 项核心回归、335969 次断言通过；31 项 Minecraft 无窗口适配检查通过。其中新增检查覆盖真实字体中文覆盖、最终像素字号生成、半透明抗锯齿像素、实体笔画、光标命中、截断宽度、长输入滚动起点、无原生字体的输入模型与选区替换。

已生成并目视检查 validation/independent-ui-font-0.3.5.png，内容为同一 OutlineFont 产生的 18 / 22 / 28 像素文字。它是独立字体栅格输出样张，不是游戏窗口截图。

完整构建通过，字体/授权/叠加层类已核对打包。本轮未启动游戏；实际 GPU 合成、鼠标/剪贴板交互、资源重载与窗口切换仍需游戏验收。没有 UI FPS 或 P95 性能实测结论。
