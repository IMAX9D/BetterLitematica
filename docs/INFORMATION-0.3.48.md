# 0.3.48 方块信息与容器

只读核对用户提供的Litematica 0.15.4与MaLiLib 0.16.3：常驻信息为方块ID及全部BlockState属性，朝向属于facing/axis等属性；按住I可查看方块名字、图标、ID、属性与预期/实际对照，容器显示完整槽位图标并合并符合连接条件的双箱。原版并非通用NBT树查看器，也没有该面板的目标坐标行。字节码及版本证据见validation/original-info-reference/REPORT.md。未复制原版代码或引入依赖。

本项目保留坐标，扩展投影/实际两列，显示名字、图标、ID、完整状态与有界NBT摘要；不再只列不同属性。HUD完整展示常规最多54槽，物品带数量，空槽保留。默认I打开独立可滚动详情，每侧独立滚动并可悬浮查看物品名称、附魔等提示；显示设置页也有方块详情入口。按键可在快捷键设置中修改。

投影读取实际合成所有者、子区域与编辑状态对应的源NBT，并应用摆放变换；双箱按左右槽序合并。没有保存容器NBT明确提示，不伪造空箱；合法空compound才显示真空槽。单人实际容器由集成服务端线程异步只读快照提供，最多一个在途请求，500ms刷新、世界/维度/位置校验；多人客户端没有完整库存则显示“库存未同步”。不发送查询/交互包，不开箱，不生成战利品。

预算：每格NBT128KiB、8192节点、16层；摘要最多128行，长内容有省略标记；最多256槽，超限显示错误；不从渲染用的默认空方块实体推测库存。独立实体NBT不在本批范围。HUD可能省略过长摘要，I详情显示预算内全部摘要与槽位，仍不宣称任意巨大NBT无损浏览。

117项核心测试 / 562935断言、120062项适配检查和完整构建通过，其中111项信息数据专项覆盖双箱顺序、空槽、物品NBT、预算和缺失数据。日志validation/build-0.3.48-final.txt，真实游戏截图与只读检查见validation/container-info-0.3.48。实际控件/快捷键动作调用与framebuffer验收不等同于OS物理I键、多人服务器或全部模组容器验收。
