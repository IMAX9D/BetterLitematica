# 0.3.40：中性深色界面与操作恢复

统一使用 UiTheme：石墨灰背景、暖白文字、低饱和强调色与一物理像素边框。去掉亮青顶条和按钮厚下边线，主菜单按投影行数收紧，单页不显示翻页控件。文字继续按最终物理字号使用系统字体，投影世界渲染颜色不受影响。

本次修复：

- 捕获完整键盘/鼠标状态变化，最多缓存 64 条，避免 M 短按落在两个 tick 之间而丢失。保留组合键抑制和释放屏障；切换世界/窗口失焦时清空旧输入。
- 五个聊天菜单入口在聊天关闭后打开。单槽待处理、最长 20 tick；连接/世界变化或其他页面介入时取消。
- 未选投影时主菜单材料入口禁用；直接进入材料页显示“未选择投影”，不再误报已移除。校验页区分尚未校验、进行中及结果状态。
- 打印设置增加“放弃更改”；正常返回与 Esc 仍校验并保存合法草稿。错误仅在当前页呈现，编辑即清，不向世界 HUD/聊天重复发送。
- 复制、粘贴、撤销及重做图标有键盘焦点边框；高亮颜色输入增加带透明棋盘的实时色块。

Windows / JDK 17 下 117 项核心测试、562935 次断言和 95685 项真实 Minecraft 依赖适配检查通过，完整 Fabric 构建通过。新增 30 项入口回归涵盖短按、组合键、队列溢出、会话变化和延迟菜单打开。日志见 validation/core-0.3.40.txt 与 validation/build-0.3.40.txt。

真实页面截图与操作复验记录保存在 [validation/ui-0.3.40](../validation/ui-0.3.40/REPORT.md)。无辅助菜单程序，英文输入状态下短按 M 直接打开；材料聊天命令正常打开，无目标文案正确。非法输入局部报错、改正清错、合法/非法草稿放弃后重进仍为原值 8、合法 Esc 保存为 12 均已实际走查。颜色预览、尚未校验状态及材料网格已检查。新主题标准窗口 1440×900 已复验；本轮没有重新测试小窗口或全部 GUI 缩放档。

本轮观察到中文输入法会拦截 M；上一轮没有排除该因素，因此旧失败截图不能单独证明采样问题。短按事件回归提供独立代码证据。切页后的少数首帧文字会等待异步字形，稳定材料截图已恢复完整；不宣称全页零闪烁。没有修改原存档或原投影文件。上一轮退出时的原版区块线程池拒绝任务日志尚未确定归属，不以修改界面掩盖该日志。
