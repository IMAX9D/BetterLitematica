# 空间编辑与草稿恢复 · 0.3.34

入口：投影配置 → 投影编辑 → 进入编辑。进入按钮悬停展示当前游戏绑定。默认左键删除、右键相邻放置、Shift+右键替换命中格，中键取样完整状态，Esc 返回编辑页；默认 Ctrl+Z/Y 撤销/重做，可在快捷键中修改。菜单与世界输入保持一致，文本框聚焦时不接管编辑快捷键。

## 行为与数据

- 一个会话固定一个摆放及源区域身份。编辑不修改真实世界，也不覆盖原投影文件；同源的其他摆放保持原内容。
- 单格与直线模式；直线由一次点击触发，最多 10001 格，同状态连续推进。命中面中心/边缘决定延伸方向，也可明确指定六个轴向。区域边界、分层、不同状态或未加载投影段会截断。
- 自动区域模式逐格检查合成后的所有者，避免删到重叠区域下的隐藏数据；显式子区域模式限定该区域。逆向旋转/镜像后写入源坐标与状态。
- 手持放置采用实际 BlockItem 上下文和状态预测，保留 BlockStateTag（例如光源等级）；编辑也可指定完整状态。
- 同类型普通属性修改保留方块实体和方块计划刻；流体身份改变时清掉旧流体计划刻。删除后撤销可恢复原容器内容和计划刻。运动活塞内部方向修改不做猜测。
- 完整源另存保留未知根标签、区域标签、实体及未修改数据；写入前后核对原源 SHA，流式打包方块数组。新文件加载及摆放配置持久化成功后才结束草稿；失败或取消保留原草稿。
- 渲染、材料、校验及整源消费者共享草稿版本。粘贴、命令、转换、项目快照在后台使用冻结的完整源合并结果，临时文件用后释放。

## 生命周期与预算

草稿在 `config/betterlitematica/placements/<世界身份>.blps.draft`。每次提交/撤销/重做生成不可变检查点，独立串行写入器合并新请求，写失败保留并重试。恢复先核对世界、UUID、源摘要、区域和调色板，再恢复差量与两向历史；从不自动进入编辑或恢复施工任务。

恢复异常可从 M → 恢复编辑重试；可作为新摆放恢复以保留现有文件关联，或把原恢复文件归档后解除恢复状态。归档不会删除恢复内容。

临时源编辑前在 `schematics/.betterlitematica-drafts/` 建立按摘要校验的持久底本；复制期间持有源租约。取消尚未采用的底本有文件提交竞争保护和有界清理队列。已采用底本不自动删除。

差量上限 65536 格 / 4096 区段，单动作上限 16384 格，历史总上限 262144 格 / 128 动作；写入器最多保留 16 个世界路径、128 MiB 快照，文件最多 64 MiB。超限拒绝候选，保留已提交的草稿与历史。整文件批量替换仍另存输出，不进入空间草稿撤销历史；未宣称无限规模或与上游共享源编辑完全相同。
