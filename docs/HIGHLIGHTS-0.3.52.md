# 0.3.52 进入高亮范围的刷新延迟

旧版0.3.51隔离实机基线：投影源数据已知、施工高亮范围8，沿+X以0.25格跨入后24tick才出现marks和可绘制boxes；+Z为1tick；0.02格小步+X为14tick。逐tick原始数据见validation/highlight-entry-baseline-0.3.51/result.json。该结果针对固定夹具，不等同于所有场景的最坏时间。

原因：旧附近扫描复用打印机候选半径（实际半径+2.598格），移动frontier补的是扩张球外沿；真实高亮球的新进入位置会落在旧扩张球内部，等常规全扫。未知源/世界状态也依赖常规轮询；world changed对没有旧标记的位置没有优先入口。几何仅FIFO重建两个区段会叠加等待。

实现：附近高亮专用NearbyScan，以玩家眼位到方块AABB的真实球面新旧差集补扫，包含同一格内小数位移；持续全扫获得固定份额，未改打印机共用PrinterScan。已变化世界位置即使之前无mark也进入去重优先队列，区块事件按附近局部处理，未知源/世界状态进入有界轮转重试。未知仍不当空气。

每tick最多512次真实采样、0.75ms采样时间额度，计时从投影快照准备完成后开始；另最多512二维规划行、64次UNKNOWN重试，事件/未知队列各4096，区块队列64。该时间不包含快照准备与几何合并，不是整个tick硬上限。几何每tick合并最多2区段；尚未合并区段按已知mark立即输出精确单格盒，删除/离开范围也立即使旧合并几何失效。

专项NearbyMovementChecks独立32,086项通过，覆盖正负方向、负Y、小数移动、持续运动、事件、未知重试、队列/工作界限和几何可见性。独立核心118测试/562955断言、完整Fabric构建158729适配检查通过，日志validation/core-0.3.52.txt及validation/build-0.3.52.txt。原NearbyProjectionChecks的512读取和时间限制断言未放宽。最终候选同夹具实机通过：+X从24降为1tick，+Z维持1tick，小数+X从14降为1tick；mark与可绘制box均在同一首次tick出现，三张framebuffer确认橙框可见。第三人称相机距约11.95/11.98格、玩家仍在8格内，0.3.51玩家中心修复保持。数据见validation/highlight-entry-0.3.52/result.json，对照见validation/highlight-entry-baseline-0.3.51；固定已知源的三组测试不等于所有范围/负载/冷加载下的1tick保证。测试进程24756已退出。
