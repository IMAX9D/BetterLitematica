# 0.3.50 空间高亮

正常施工高亮新增多余方块：启用投影的有效选区内部、源数据明确为空气且世界为非空气时显示粉红线框，与校验多余颜色一致。缺失橙、错误红，沿用呼吸效果和统一置顶开关。未知源数据/未加载区块不当空气；投影选区外不高亮。相同几何的多投影沿用现有合成顺序。

打印机→高亮：范围默认8格，可设1–32；高亮上限默认0，不限制当前工作集绘制数量，可设置1–1000000。设置上限时按相机到盒子的最近距离排序，按合并后线框计数。施工附近与短期动作反馈使用此范围；校验保留128格可见范围，不缩小到施工半径。各绘制通道分别应用上限。

连续同类位置按X/Y/Z完整游程合并，并进一步合并边界吻合的相邻区段盒；不填空洞、不合并不同类型。不是任意连通形状的包围盒，不以大盒吞入正确方块。附近检查仍每tick最多512游标/0.75ms扫描额度，合并每tick最多2个16³区段，取消2048标记和40tick老化截断；空间范围自然限制附近缓存数量。世界事件标脏，下一次增量合并刷新。
