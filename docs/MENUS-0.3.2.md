# 0.3.2 菜单排版

12 个菜单统一使用 MenuScreen：居中深色面板、青色强调、统一间距和按钮高度。主菜单三列按投影管理、施工检查、工具组织；表单与列表分别限制最大宽度，避免大窗口横向拉伸。

固定头部包含标题和说明；中间内容超高时支持滚轮及 PageUp/PageDown；底部固定返回、分页和状态。底栏显示中文摆放概况，渲染诊断仍保留在游戏 HUD/信息入口。列表提供页码、边界禁用和空状态；搜索输入更新列表时保留输入框。长按钮可悬停查看完整文字。

- 设置：交互 / 快捷键分页面；开启、关闭、工具模式和快捷操作名称改为中文。
- 摆放：统一选择高亮；未选中时配置、复制、重载、移除置灰；锁定时变换操作置灰。
- 选区：名称、角点、原点、区域列表、捕获分别成组。
- 分层：轴、范围、微调、不透明度分别排布。
- 材料 / 校验：双标签、搜索、扫描工具栏、过滤与 HUD、结果列表。
- 编辑：独立字段标签，重建/缩放界面时保留输入内容。
- 创造：中文替换规则；设置与写入、暂停、取消分开。
- 项目：名称、版本操作、版本列表分组；编辑名称不重建正在输入的字段。
- 任务：任务列表分页，取消操作独立。

验证：56 项核心回归、22 项无窗口 Minecraft 适配检查和完整 Fabric 构建通过。另对 5 种逻辑尺寸（320×240、426×240、640×360、960×540、1920×1080）的主菜单/表单/列表框架进行了 150 个列位置与底栏边界算术检查。没有新增机械重复的单元测试，也没有启动 Minecraft；算术检查不能代替实际界面截图、缩放、鼠标和键盘操作验收。
