# 0.3.45 颜色选择与统一高亮

打印机高亮页的四个颜色预览现在可点击进入颜色选择器。色轮调节色相与饱和度，另有明度和0–255不透明度滑杆，实时显示预览及ARGB。确定回填打印机草稿；取消或Esc不修改原色。原十六进制输入保留，非法色值也能通过选择器恢复。下方恢复默认仅重置四项颜色，其他设置及未保存输入保留；最终仍由打印机页面的保存/返回应用，放弃更改沿用原逻辑。

顶部“穿透显示”改为“高亮置顶”，去掉底部独立错误开关。附近橙红线框、打印动作高亮及校验结果高亮共用深度规则，显示设置页的重复错误穿透入口也移除。旧配置任一旧开关开启则迁移为开启；保存后移除旧字段，新开关优先。普通投影表面、选区/摆放边界保持原绘制规则。

颜色选择器沿用独立UI和系统字体，单页复用一个512×512轮盘纹理，关闭释放；可用鼠标点击/拖动和方向键调节，滑杆支持Home/End。

完整构建通过：117项核心测试、562935次断言、119951项适配检查，包括21006项颜色数学回归和开关迁移检查。日志见 validation/build-0.3.45.txt。

实际GUI验证见 validation/color-picker-0.3.45：真实Screen鼠标点击/拖动/释放、Esc派发与4张framebuffer；选色58D6C13C回填草稿但不提前保存，取消保持不变，恢复颜色保留1234ms、置顶关闭和其他页7/tick草稿，保存后应用。仅一个高亮置顶入口。测试进程已退出，用户游戏未操作；不将菜单回调等同于操作系统物理键鼠验收。
