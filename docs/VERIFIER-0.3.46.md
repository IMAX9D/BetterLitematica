# 0.3.46 校验高亮

移除校验结果行的定位按钮、定位标记、清除定位入口及HUD方向/距离文案，结果行保留忽略/恢复，文本区随之加宽。准星方块信息属于独立功能，保持不变。

按用户最新要求，校验页高亮开启即使用穿透世界深度的渲染层，并在其他投影反馈后绘制。它不再依赖打印机的高亮置顶偏好；校验页“高亮”仍负责开/关。打印机与附近施工高亮保留已有统一开关，避免开启校验时改写其他设置。

缺失使用与玩家附近预览共用的橙色常量，错误方块和错误属性共用红色常量，呼吸透明度也沿用同一函数。多余与未知保持已有配色。

真实隔墙验收揭示共同深度问题：1.20.1的RenderPhase.ALWAYS_DEPTH_TEST在GL_ALWAYS时setup/teardown均为空操作，会继承此前深度状态。之前附近线框对照中的其他图层恰好关闭了深度，不能证明独立绘制时也可靠。OverlayLayers现使用专用DepthTest，在实际绘制阶段明确关闭深度、结束后恢复之前开关；所有置顶图层均受益。

最终候选实机对照通过：关闭投影表面及打印机高亮、打印机置顶为false时，校验开启仍能在实体墙面看见橙缺失/红错误，目标区域363橙/453红像素；关闭校验高亮为0/0。真实校验列表的忽略/恢复及samples变化通过，隔离进程已退出。独立深度状态17项真实GL断言验证初始开启/关闭均能正确恢复且不修改深度比较函数，证据见validation/overlay-depth-0.3.46。
