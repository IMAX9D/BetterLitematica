# 0.3.54 Tab 独立开关轮盘

按住Tab呼出一级轮盘，左键“模式选择”进入二级；打印/挖掘/排流体/填充互相独立，可以叠加。中心返回一级，松开Tab即关闭，Esc/失焦/世界或连接变化也关闭且需释放再按。已在其他GUI时Tab保留原导航，不抢占文本输入；游戏内占用默认Tab玩家列表绑定，避免同时出现。

挖掘聚合原breakWrong/breakExtra/breakState，打开全部、关闭全部；原有部分组合显示“部分”，细分设置仍在打印机配置。沿用现有范围、过滤、协议及权限。四项修改只configure并保存，不自动启动；既有配置暂停语义保留，CapsLock仍管理施工运行。修复后端挖掘被print开关套住的问题：仅挖掘也可启动/发现/执行BREAK，不会对空气挖掘或执行PLACE/ADJUST。

使用MenuScreen预览画布与IndependentUi物理像素扇环、系统字体，中性灰与低饱和金色表示开启。没有打包字体。点击环间隙/中心不误切开关，点击一个扇区仅切当前项；一级进入二级的同一次点击不会触发二级开关。

输入由键盘HEAD物理Tab事件+START tick兜底驱动；只关闭自己拥有的screen，Esc后仍按住不重开；释放后清attack/use/pick并等物理鼠标松开，避免按住鼠标跨屏穿透。快速M→Tab开关→M释放会清旧快捷键队列，防延迟打开菜单。MODE生命周期与开关813项检查通过，几何命中10项。
